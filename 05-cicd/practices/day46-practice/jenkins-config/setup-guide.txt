[ STEP 1: Start Jenkins ]

  cd ~/DevOps-journey/05-cicd/practices/day46-practice/jenkins-config
  docker compose up -d

  This starts Jenkins on: http://localhost:8090
  First start: ~60 seconds to initialize

[ STEP 2: Get Initial Admin Password ]

  Method 1 (from container logs):
  docker logs jenkins-day46 2>&1 | grep -A 5 'initial admin password'

  Method 2 (from file):
  docker exec jenkins-day46 cat /var/jenkins_home/secrets/initialAdminPassword

  This password is required for first login
  Jenkins generates it on first run
  One-time use: changes after initial setup

[ STEP 7: Security Configuration ]

  Manage Jenkins → Security:
  Authorization: Matrix-based security
  Add admin user: full permissions
  Other users: build/read only

  Security checklist:
  ✅ Enable CSRF protection
  ✅ Enable security realm
  ✅ Disable agent-to-master security
     (only for trusted internal agents)
  ✅ Use HTTPS in production
  ✅ Configure backup
