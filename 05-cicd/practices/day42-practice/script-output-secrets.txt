[ METHOD 1: GitHub CLI (gh) ]

  Install: sudo apt install gh
  Login:   gh auth login

  Set repository secret:
  gh secret set SECRET_NAME
  (prompts for value securely)

  Set from file:
  gh secret set SECRET_NAME < secret.txt

  Set from environment variable:
  echo "$MY_VALUE" | gh secret set SECRET_NAME

  List secrets:
  gh secret list

  Delete secret:
  gh secret delete SECRET_NAME

[ METHOD 2: GitHub Web UI ]

  Repository secrets:
  Repo → Settings → Secrets → Actions
  → New repository secret
  Name: MY_SECRET
  Value: the-actual-secret-value

  Environment secrets:
  Repo → Settings → Environments
  → Select environment
  → Add secret

[ METHOD 3: GitHub API ]

  curl -X PUT \
    -H 'Authorization: token PAT' \
    -H 'Accept: application/vnd.github+json' \
    https://api.github.com/repos/OWNER/REPO/actions/secrets/NAME \
    -d '{"encrypted_value": "...", "key_id": "..."}'

  Note: Value must be encrypted with repo public key
  Use: gh secret set (handles encryption)

[ SECRETS NAMING CONVENTIONS ]

  Repository secrets (global):
  DOCKERHUB_USERNAME
  DOCKERHUB_TOKEN
  SONAR_TOKEN
  SLACK_WEBHOOK_URL

  Environment secrets (per-env):
  DB_PASSWORD          (different per env)
  DB_CONNECTION_STRING (different per env)
  AWS_ROLE_ARN         (different per env)
  REDIS_URL            (different per env)

  OIDC (no secrets needed!):
  AWS_ROLE_ARN: arn:aws:iam::123:role/github-role
  (IAM role trusts GitHub OIDC - no key needed)

[ WHAT SHOULD BE A SECRET vs VARIABLE ]

  SECRET (encrypted, masked in logs):
  ✅ Passwords
  ✅ API keys and tokens
  ✅ Connection strings with credentials
  ✅ SSH private keys
  ✅ Certificate private keys

  VARIABLE (visible, not encrypted):
  ✅ Region names (us-east-1)
  ✅ Application names
  ✅ Non-sensitive URLs
  ✅ Feature flags
  ✅ Version numbers
  ✅ Timeout values

[ GITHUB SECRETS USED IN DEVOPS JOURNEY ]

  For Docker (Day 44):
  DOCKERHUB_USERNAME = your Docker Hub username
  DOCKERHUB_TOKEN = Docker Hub access token

  For AWS (Phase 6):
  AWS_ACCOUNT_ID = your AWS account ID
  (OIDC replaces access keys)

  For notifications:
  SLACK_WEBHOOK_URL = Slack incoming webhook

  Built-in (no setup needed):
  GITHUB_TOKEN = automatic per-run token
