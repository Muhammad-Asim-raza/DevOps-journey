============================================
   ALGORITHM COMPARISON SUMMARY

Round Robin    : Equal distribution, simple
Weighted RR    : For unequal server capacity
Least Conn     : Best for varied request time
IP Hash        : Sticky sessions, same server
Random         : Simple random selection
First          : Fill server before next one
