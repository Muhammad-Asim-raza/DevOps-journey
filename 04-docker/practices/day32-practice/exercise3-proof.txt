=== ECR REFERENCE ===
ECR Workflow:
1. aws ecr create-repository --repository-name myapp
2. aws ecr get-login-password --region us-east-1 |
   docker login --username AWS --password-stdin ACCOUNT.dkr.ecr.REGION.amazonaws.com
3. docker tag myapp:v1.0 ACCOUNT.dkr.ecr.REGION.amazonaws.com/myapp:v1.0
4. docker push ACCOUNT.dkr.ecr.REGION.amazonaws.com/myapp:v1.0

Key differences vs Docker Hub:
- Authentication via AWS IAM (no passwords)
- Private by default
- Integrated with ECS/EKS
- Same AWS network (fast pulls)
- Lifecycle policies auto-clean old images
- Image scanning for vulnerabilities

Scripts created:
- ecr-workflow.sh (full push workflow)
- ecr-lifecycle-policy.json (auto-cleanup policy)
