--- BuildKit cache mount benefit ---
Without cache mount:
  Every build downloads all packages again
  Build time: 30-120 seconds for large deps

With --mount=type=cache,target=/root/.cache/pip:
  First build: downloads (slow)
  All subsequent: uses cache (very fast!)
  Cache NOT stored in image layers
  Image stays small
