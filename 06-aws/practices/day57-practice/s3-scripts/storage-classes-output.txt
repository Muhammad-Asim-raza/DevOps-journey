[ DETAILED EXPLANATION ]

  S3 STANDARD:
  - 3+ AZs redundancy (highest durability)
  - Immediate access
  - No minimum storage duration
  - Use: active content, frequently accessed data
  - Cost: s3-scripts/02-storage-classes.sh.023/GB/month

  S3 INTELLIGENT-TIERING:
  - Automatically moves objects between tiers
  - Frequent, Infrequent, Archive tiers
  - Small monitoring fee per object
  - Use: unknown or changing access patterns
  - Great for: mixed workloads you can't predict

  S3 STANDARD-IA (Infrequent Access):
  - Same durability as Standard (3+ AZs)
  - Retrieval fee per GB
  - Minimum 30-day storage charge
  - Use: backups accessed monthly
  - Cost: s3-scripts/02-storage-classes.sh.0125/GB/month storage + retrieval

  S3 ONE ZONE-IA:
  - 1 AZ only (20% cheaper than Standard-IA)
  - If AZ goes down: data UNAVAILABLE
  - Use: ONLY for recreatable data
  - Example: thumbnail images (regeneratable)
  - Never for: primary backups, critical data

  S3 GLACIER INSTANT RETRIEVAL:
  - Same speed as Standard
  - Minimum 90-day storage
  - Use: quarterly accessed archives

  S3 GLACIER FLEXIBLE RETRIEVAL:
  - 1-5 hours retrieval (Expedited: minutes for $)
  - Minimum 90-day storage
  - Use: backups, disaster recovery archives

  S3 GLACIER DEEP ARCHIVE:
  - Cheapest option ($0.00099/GB/month)
  - 12-48 hours retrieval
  - Minimum 180-day storage
  - Use: compliance data, 7+ year retention
  - Example: medical records, financial records
