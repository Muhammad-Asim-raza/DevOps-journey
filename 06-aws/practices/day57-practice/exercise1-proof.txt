=== S3 FUNDAMENTALS ===
S3 = object storage (not file system, not block storage)
Bucket: globally unique container
Object: file stored in bucket
Key: the "path" of the object (not a real folder)
Durability: 99.999999999% (11 nines)

Bucket creation:
aws s3api create-bucket --bucket NAME --region REGION
# us-east-1 does NOT need LocationConstraint
# All other regions DO need --create-bucket-configuration LocationConstraint=REGION

Security after creation:
1. Block all public access
2. Enable versioning
3. Enable default encryption (SSE-S3 or SSE-KMS)
4. Apply HTTPS-only bucket policy

Pricing:
Storage:    $0.023/GB/month
PUT:        $0.005/1000
GET:        $0.0004/1000
Data OUT:   $0.09/GB
Data IN:    FREE
