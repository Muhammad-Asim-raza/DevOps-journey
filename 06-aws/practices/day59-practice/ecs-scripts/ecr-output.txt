[ WHY ECR OVER DOCKER HUB? ]

  Docker Hub:
  ✗ Rate limits (100 pulls/6hr unauthenticated)
  ✗ Public by default (extra config for private)
  ✗ Separate credentials to manage
  ✗ No native IAM integration

  ECR:
  ✅ IAM-controlled access (same as all AWS)
  ✅ No pull rate limits (within AWS network)
  ✅ Private by default
  ✅ Same-region pulls: FREE (no data transfer)
  ✅ Image scanning (Trivy-powered, built-in)
  ✅ Lifecycle policies (auto-delete old images)
  ✅ Immutable tags (prevent overwrite)
  Cost: $0.10/GB/month after first 500MB free

[ STEP 1: Create ECR Repository ]

aws ecr create-repository     --repository-name "devops-cicd-platform"     --image-scanning-configuration scanOnPush=true     --image-tag-mutability IMMUTABLE     --encryption-configuration encryptionType=AES256     --tags Key=Name,Value="devops-cicd-platform"            Key=Project,Value="devops-journey"     --region "us-east-1"
  (Print only - ECR repository not created)

  Settings explained:
  scanOnPush=true:       scan every pushed image
  IMMUTABLE tags:        sha-abc123 cannot be overwritten
  AES256 encryption:     at-rest encryption

  ⚠️  IMMUTABLE is best practice:
  Without: overwrite sha-abc123 with different image
  With:    sha-abc123 ALWAYS = same image (safe)
