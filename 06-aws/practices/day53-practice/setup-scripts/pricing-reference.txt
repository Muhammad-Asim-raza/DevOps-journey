============================================
   AWS PRICING MODEL
   Understanding how AWS bills you
============================================

[ PRICING PRINCIPLES ]

  1. Pay for what you use
     No upfront costs (most services)
     No termination fees
     Stop using = stop paying

  2. Pay less when you use more
     S3: first 50TB cheapest tier
     Data transfer: first GB most expensive

  3. Pay even less with reservations
     Reserve capacity 1-3 years = 30-72% discount

[ EC2 PRICING MODELS ]

  On-Demand (default):
  Pay per hour/second of usage
  No commitment
  Most expensive but most flexible
  Use: unpredictable workloads

  Reserved Instances (1 or 3 year):
  Commit to a specific instance type
  Save 30-72% vs On-Demand
  Use: steady-state production workloads

  Spot Instances:
  Bid on spare AWS capacity
  Save up to 90% vs On-Demand
  Risk: AWS can terminate with 2-min notice
  Use: batch jobs, data processing, CI/CD runners

  Savings Plans:
  Commit to dollar amount/hour
  More flexible than Reserved Instances
  Save up to 72%
  Use: when you know you'll spend X/hour

[ COMMON SERVICE COSTS (us-east-1) ]

  EC2:
  t3.micro:    $0.0104/hour (~$7.50/month)
  t3.small:    $0.0208/hour (~$15/month)
  t3.medium:   $0.0416/hour (~$30/month)
  m5.large:    $0.096/hour (~$70/month)

  S3:
  Storage:     $0.023/GB/month
  GET request: $0.0004 per 1,000
  PUT request: $0.005 per 1,000
  Data out:    $0.09/GB (first 10TB)

  RDS (MySQL, t3.micro):
  Single AZ:   $0.017/hour (~$12/month)
  Multi-AZ:    $0.034/hour (~$25/month)

  ALB:
  Fixed cost:  $0.008/hour (~$5.84/month)
  Per LCU:     $0.008/LCU-hour

  Data Transfer:
  IN to AWS:   FREE
  OUT from AWS: $0.09/GB (first 10TB)
  Between AZs: $0.01/GB each direction
  Same AZ:     FREE

[ DATA TRANSFER GOTCHA ]
  Data transfer COSTS are often the surprise!

  RDS in us-east-1a
  App server in us-east-1b
  Data between them: $0.01/GB each way
  10GB queries/day = $0.10/day = $3/month
  (small, but adds up at scale)

  ALWAYS put databases in SAME AZ as app
  For production: multi-AZ with load balancer

[ AWS COST TOOLS ]
  Billing Dashboard: current month costs
  Cost Explorer: historical + forecast
  Budgets: set alerts when approaching limit
  Pricing Calculator: estimate before building
    https://calculator.aws

  AWS Trusted Advisor:
    Checks: unused resources, overprovisioned
    Free tier: 5 basic checks
    Business/Enterprise: all 150+ checks

[ COST OPTIMIZATION TIPS ]
  1. Delete unused resources (biggest savings)
  2. Right-size instances (don't over-provision)
  3. Use Spot instances for non-critical work
  4. S3 lifecycle policies (move old data to Glacier)
  5. Reserved instances for stable workloads
  6. Turn off dev/test environments nights/weekends
  7. Data transfer: keep traffic within same AZ
  8. Use CloudFront to cache (reduces origin cost)
