[ CLOUD COMPUTING MODELS ]
  IaaS: you manage OS + apps (EC2, S3)
  PaaS: you manage apps only (RDS, Lambda)
  SaaS: you use the service (Gmail, Slack)

[ AWS GLOBAL INFRASTRUCTURE ]
  Regions:           33+ geographic areas
  Availability Zones: 3-6 per region
  Edge Locations:    400+ for CloudFront CDN

  Region naming: us-east-1, eu-west-1
  AZ naming:     us-east-1a, us-east-1b

  For High Availability: deploy to 2+ AZs

[ SHARED RESPONSIBILITY ]
  AWS: physical hardware, network, hypervisor
  You: data, IAM, OS patches, app security

[ CORE SERVICES — DEVOPS FOCUS ]
  Compute:   EC2, ECS, EKS, Lambda, Fargate
  Storage:   S3, EBS, EFS, ECR
  Network:   VPC, ALB, Route53, CloudFront
  Database:  RDS, Aurora, DynamoDB, ElastiCache
  Security:  IAM, KMS, Secrets Manager, WAF
  Monitor:   CloudWatch, CloudTrail, X-Ray
  CI/CD:     CodePipeline, CodeBuild, CodeDeploy

[ PRICING MODEL ]
  Pay as you go (no upfront)
  On-Demand: most flexible, most expensive
  Reserved 1-3yr: 30-72% discount
  Spot: up to 90% off, interruptible
  Savings Plans: flexible commitment

[ AWS CLI ESSENTIALS ]
  Install: curl from awscli.amazonaws.com
  Config:  aws configure
  Files:   ~/.aws/credentials, ~/.aws/config

  Verify:  aws sts get-caller-identity
  Regions: aws ec2 describe-regions
  Buckets: aws s3 ls

  Flags:
  --region REGION   override region
  --profile NAME    use named profile
  --output FORMAT   json|text|table
  --query JMESPATH  filter results
  --dry-run         test without executing
