=== FORK WORKFLOW REFERENCE ===

Step 1: Fork on GitHub (click Fork button)

Step 2: Clone your fork
  git clone git@github.com:YOUR-USERNAME/repo.git

Step 3: Add upstream remote
  git remote add upstream \
      git@github.com:ORIGINAL/repo.git

Step 4: Verify remotes
  git remote -v
  Output:
  origin    git@github.com:YOUR/repo.git (fetch)
  origin    git@github.com:YOUR/repo.git (push)
  upstream  git@github.com:ORIGINAL/repo.git (fetch)
  upstream  git@github.com:ORIGINAL/repo.git (push)

Step 5: Create branch and make changes
  git switch -c fix/my-contribution

Step 6: Push to YOUR fork
  git push origin fix/my-contribution

Step 7: Open PR on GitHub
  From: your-fork:fix/my-contribution
  To:   original:main

Step 8: Keep fork updated
  git fetch upstream
  git switch main
  git merge upstream/main
  git push origin main
